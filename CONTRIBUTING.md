# Contributing

Yes Chef is built by one person, and review time is short. We are not looking for outside pull requests. A PR may be closed or left open without review, and an idea in one may be built a different way later.

- **Bugs:** open an issue. Say what you did, what you expected, what happened, and your Yes Chef and T3 Code versions.
- **Ideas:** start a discussion in [Ideas](https://github.com/ddmirolli/yeschef/discussions/categories/ideas). Describe the problem first, then the change.
- **A small fix for an obvious bug** is welcome as a PR. Keep it to one problem, say how you checked it, and add before and after screenshots for anything you can see.

Before you send a change, run the checks in `AGENTS.md` under "Verify".
