A Mac app for Apple silicon, macOS 13 or later. It needs T3 Code on the same Mac, and signs in to it with T3 Connect.

 

Apple silicon (arm64).dmg

Yes Chef updates itself. When a new version is out, it asks before it downloads, then installs it when you restart or quit.

Nightly builds the newest main. It installs as its own app, Yes Chef (Nightly), with its own data, next to Yes Chef, and it updates only to newer Nightlies.

Every build is on GitHub Releases.
